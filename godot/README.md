# Raining · Godot 原型

Godot 4.7.2 验证。横屏设计尺寸 1280×720，Compatibility 渲染器，2D 等距俯视场景。雨云、地面、树木、火焰、雨滴与界面均由代码生成；雨声在启动时生成 8 秒单声道缓冲，未引入图片或录音素材。

## 试玩

用 Godot 导入本目录的 `project.godot`，按 F5 运行。桌面端按住鼠标左键，在树冠上方降雨；触屏端使用单指长按，移动触点可移动雨云。支持缩放后的横屏布局。移动设备触摸仍需真机验证。

1. 第一关：一棵树，五批有效降雨灭火，得到 10 金币，升级速度。
2. 第二关：三棵树，全部扑灭得到 30 金币，升级范围。
3. 第三关：十棵树，验证扩大范围后的多目标覆盖；结束后可停留听雨或重新开始。

当前为了完整走通教学，要求购买对应升级后进入下一关；重新开始有确认弹窗。进度保存在 Godot 的 `user://raining_v1.json` 中，正式小游戏端存储适配待做。

```sh
godot --headless --path godot --script res://tests/test_progress.gd
godot --headless --path godot --script res://tests/test_scene.gd
```

从仓库根目录执行。已通过 15 项进度检查及 9 项场景、鼠标事件、合成音频缓冲检查；场景测试使用内存进度，不覆盖玩家存档。

本地窗口手动验证了三关通关、金币配平、两次升级和重置；改为雨云及等距布局后重新验证了首关，自动场景测试覆盖更新后的全部三关。Godot 已确认可以读取本地检查点。声音已启动并提供开关，主观音色仍需继续评估。

## 包体与导出

Godot 项目独立放在本目录，仓库根目录的参考录音、文档和网页编辑工具不属于本工程。`export_presets.cfg` 提供关闭线程的 Web 预设，排除测试目录。

已成功导出并用 Godot 加载 `build/raining.pck`，本次资源包为 24,316 字节，约 23.7 KiB。它只包含游戏资源与脚本，**不含 Godot 引擎/WASM，因此不是最终小游戏包大小**。构建产物和 `.godot` 缓存不提交 Git。

本机尚未安装对应 Web 导出模板；完整 Web 导出、TapTap 转包、平台 API 与真机扫码测试尚未完成。当前交付是本地可玩 Godot 原型，不能据此认定 TapTap 发布链路已经打通。SystemFont 在本机支持中文，小游戏端的中文字体需要另行验证，必要时引入合法的小型字体子集。

## 美术方向

已确认：用雨云表达降雨范围；采用类似《红警》的 2.5D 等距俯视视角。当前用菱形地块、立体侧边、分面树冠和深度排序实现，仍是程序化原型美术。

参考评估：用户询问《Keep on Mining!》和《八方旅人》的纯代码实现可行性。核对[前者官方商店截图](https://store.steampowered.com/app/3769130/)后，其主要特征为描边、色块与等距卡通物件，可作为后续轮廓、细节和场景密度的参考；尚未确认将其作为最终风格。《八方旅人》级别的 HD-2D 需要大量专门制作的素材和灯光打磨，不承诺纯程序生成达到同等品质。未复制任何参考游戏素材到工程。
