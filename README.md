# Raining

一个从下雨延伸到各种天气现象的增量游戏，搭配白噪音帮助玩家入眠。

核心操作参考《账单必须支付》，玩家只需要触摸屏幕。

雨、风、雷构成三套可升级系统。核心玩法采用关卡制，不同关卡有不同场景，并提供不同白噪音。
