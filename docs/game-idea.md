## 概念探索：听雨小屋（暂定提案）

以下内容来自讨论中的初步建议，尚未由用户确认，不作为已经确定的需求。其中收取资源、选择建设等操作需要按“玩家只需触摸屏幕”的已确认方向重新评估。项目名称暂用仓库名 Raining，“听雨小屋”仅为候选名称。

### 体验概念

白天经营雨景，夜晚听雨入眠。玩家从一间小木屋和一只接雨的水桶开始，收集雨水、建设环境，逐步拥有自己的雨中小天地。

### 增量循环

下雨 → 收集雨水 → 建设环境 → 解锁新雨景与声音 → 提高雨水收益。

可探索的成长方向：

| 方向 | 示例内容 | 体验目标 |
| --- | --- | --- |
| 小屋 | 木窗、屋檐、壁炉、玻璃天窗 | 温暖与归属感 |
| 自然 | 苔藓、花园、竹林、池塘 | 让环境随着积累逐渐生长 |
| 雨声 | 雨打树叶、屋顶、窗户、水面 | 自由组合喜欢的声音环境 |

### 候选特色：让升级听得见

环境建设同时解锁对应的声音。例如建造池塘后解锁雨落水面的声音，种植竹林后解锁叶间雨声。各层声音可以单独调节，玩家可以保留自己喜欢的听感。

### 两种使用状态

- 经营状态：收集雨水、选择建设、发现雨中访客，每次几分钟即可完成一轮操作。
- 入眠状态：隐藏数字和操作，画面渐暗，保持稳定雨声；进度继续积累，可以选择结束时间。

入眠体验的候选原则：避免奖励弹窗、突然的雷声、必须立即处理的事件和高频点击；支持离线成长，减少连续签到与定时收取带来的压力。

### 第一版范围建议

以一扇窗外的雨景验证核心体验：

- 小屋、花园、池塘三个建设区域。
- 十来项升级。
- 三到五层可混合的环境音。
- 离线收益。
- 入眠模式。

优先验证建设是否带来期待感，以及玩家是否愿意停止操作、继续听雨。大地图、天气收集和转生系统暂列为后续可探索内容。

## 待讨论的问题

- 首发平台：手机睡前游戏，还是电脑桌面常驻雨景小窗？
- 整体美术风格与视角。
- 触摸的具体形式、对雨与收益的影响，以及停止触摸后的表现。
- 增量系统的复杂度，以及主动操作和放置的比例。
- 白噪音的素材来源、混音方式与入眠状态的持续播放方式。
- 是否采用“听雨小屋”概念，以及最终游戏名称。
